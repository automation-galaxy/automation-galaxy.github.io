VCF 9 Automation Bulk Onboarding Update

NOTE: The bulk onboarding solution has been refactored to support VCF Automation 9.x and is designed to run from the Aria Automation Orchestrator (vRO).

I am excited to announce a major refactor to the Bulk Onboarding utility to bring full support for VCF Automation 9.x environments. With this latest release, you can seamlessly perform bulk onboarding of legacy Aria Automation deployments directly into the target **VCF Automation VM-Apps** organization.

While the underlying operational mechanics remain familiar, dedicated workflows labeled with the -vcf9 suffix have been introduced to handle modern token-based authentication, target validation, and deployment onboarding for VCF 9 targets.

What's New in VCF 9 Automation Onboarding

  • VCF 9.x Architecture Support: Refactored code structure to accommodate VCF Automation 9 endpoints and target structures.
  • VM-Apps Organization Target: Direct bulk onboarding support into VCF Automation VM-Apps organizations.
  • Dedicated VCF 9 Workflows: Specialized workflow extensions designed to run seamlessly from Aria Automation Orchestrator.

Workflow Structure Changes

The end-to-end process follows a similar logical path to previous iterations, but requires running the specific -vcf9 workflow variations in place of older versions:

Previous Aria Automation blog post contains detailed steps on all workflows and can be accessed here

  1. 1. configureBulkOnboardingUtility: Configure your connection settings. A dedicated tab has been added specifically for VCF 9 Automation.

  2. 2. captureMachineDatavRA8 (or legacy source capture equivalent): Gathers inventory data from the source environment.
  3. 3. validateOnboardingCSV-VCF9: Runs validation checks tailored for VCF 9 target compliance and mapping integrity.
  4. 4. onboardMachines-VCF9: Executes the primary onboarding sequence to register workloads under the VCF Automation 9 environment.
  5. 5. postOnboardingOperations-VCF9: Finalizes post-deployment operational configurations.
